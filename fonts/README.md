# fonts

Fonts Voxline's in-app font picker downloads on demand for the lyric overlay. All pulled from [Google Fonts](https://github.com/google/fonts) and distributed here under the [SIL Open Font License](https://openfontlicense.org/).

| file | family |
|---|---|
| Poppins-Bold.ttf | Poppins |
| Outfit-Bold.ttf | Outfit |
| Montserrat.ttf | Montserrat (variable) |
| Raleway.ttf | Raleway (variable) |
| Inter.ttf | Inter (variable) |
| Manrope.ttf | Manrope (variable) |
| Lexend.ttf | Lexend (variable) |
| Nunito.ttf | Nunito (variable) |
| Rubik.ttf | Rubik (variable) |

Add a `.ttf`/`.otf` file here and it shows up in Voxline's font dropdown next launch, no app update needed.
